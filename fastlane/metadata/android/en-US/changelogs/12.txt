The whole interface is now bilingual: every screen ships in English and Arabic through proper Android string resources, with full right-to-left layout mirroring on Arabic devices (the terminal console itself stays pinned left-to-right because a shell is inherently LTR). Android 13+ users can pick the app language per-app from system settings via localeConfig; earlier versions follow the system language. Localization covers onboarding, agent hub, chat, projects, files, changes, preview, and settings, with correct Arabic plural forms for count-based labels. Strings produced inside the runtime layer (view-model status messages and agent activity titles) remain English for now and are tracked as the next slice of this work.
