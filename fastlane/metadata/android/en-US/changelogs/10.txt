The private Ubuntu environment gets a recoverable upgrade path (experimental): Settings → Linux base can move the runtime to Ubuntu 24.04 while keeping the entire 20.04 environment on disk as a rollback until your first task completes on the new base — and an upgrade interrupted by Android is repaired automatically at the next start. On-device maintenance no longer runs unattended apt upgrades: security patches now ship inside verified, digest-pinned Core bundle rebuilds, so two devices on the same bundle hold identical package state. The upgrade row appears only once a verified 24.04 bundle is published for this release channel.
