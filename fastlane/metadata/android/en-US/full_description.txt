Mobile Harness is a local-first AI development workspace built for ARM64 Android phones.

Create persistent projects or start a Quick Project, chat with a coding agent, inspect files, run Linux commands, review changes, and preview local web apps—without installing Termux or rooting your phone.

Features:
• Persistent projects and friendly, instantly created Quick Projects
• Streaming AI chat with visible tool activity and multiple sessions
• Project-scoped and global Linux terminals
• Collapsible file browser with locally stored attachments
• File diffs, task checkpoints, and rollback controls
• Browser-style preview for local web servers
• Guided Ubuntu 20.04 ARM64 runtime setup with live progress
• Anthropic API and experimental Anthropic-compatible gateways
• API-key encryption backed by Android Keystore

Important: Mobile Harness is experimental alpha software. PRoot is not a hardened security sandbox. Open only projects and dependencies you trust. Provider capabilities vary, and some models may not support every Claude Code tool or streaming event.
