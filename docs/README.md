## Project goals

Mobile Harness aims to make software development possible from a phone by combining:

- a mobile-first UI
- a real Linux environment
- on-device coding agents
- local build and preview workflows
- secure handling of credentials and runtime updates

This is a developer-focused project with a strong emphasis on usability, portability, and workflow quality.
