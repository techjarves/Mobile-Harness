# Roadmap

## Near-term goals

- polish onboarding and setup flow
- improve diagnostics and error reporting
- expand provider compatibility and validation
- improve project session persistence and recovery
- strengthen documentation for contributors and users

## Medium-term goals

- improve local build and test workflows for Android projects
- improve preview and local app debugging
- add more automation for runtime installation and updates
- make build compatibility clearer across device classes

## Long-term goals

- make the mobile dev environment more reliable for full-stack work
- extend AI-assisted coding workflows for multi-file projects
- refine project security and sensitive-data handling
- improve discoverability and maintainership for wider community adoption

## Community priorities

The strongest areas for contribution are:

- Android runtime reliability
- onboarding and setup UX
- documentation
- security and privacy improvements
- provider compatibility and tool integration

This roadmap is meant to stay practical: prioritize a useful, stable mobile coding environment before adding broad experimental scope.
